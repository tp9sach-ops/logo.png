# QUÁN NHẬU BẤT ỔN — dự án web 3D TikTok LIVE

Đây là thư mục riêng của dự án. Không dùng hoặc ghi đè các file ở thư mục gốc repository.

## Phiên bản mã nguồn đang phát triển
- Bản local: v0.2.5 (Phiên A5).
- Dựng phố 4 quán nhậu miền Tây bằng Three.js.
- Nhân vật chibi procedural dùng InstancedMesh; 200 ghế và khu chờ.
- Có bàn ghế, trang trí quán, xe và mâm thức ăn 3D.
- Three.js được import từ `node_modules/three/`; chạy `npm install` trước.

## Chạy local
Trong thư mục dự án:
```bash
npm install
npm run demo
```
Mở `http://localhost:8080`.
